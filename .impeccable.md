## Design Context

### Users

Developers coordinating multiple coding-agent conversations across repositories and workspaces. They need to scan live activity, find attention states, and move between concurrent work without losing context.

### Brand Personality

Calm, precise, and quietly expressive. BB should feel like a capable technical instrument: dense enough for daily work, but never noisy or theatrical.

### Aesthetic Direction

Conductor-like information architecture within BB's existing adaptive theme and typography system. Motion is restrained and functional, with light and dark modes inherited from the host.

### Design Principles

- Make hierarchy and live state legible at a glance.
- Keep frequent actions fast, compact, and keyboard accessible.
- Use motion to explain state changes and spatial relationships.
- Preserve full functionality on compact and touch layouts.
- Respect host theme tokens and reduced-motion preferences.
